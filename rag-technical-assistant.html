RAG Technical Assistant & Onboarding Agent

Two distinct operational challenges for a Tier-1 automotive electronics client (via Tata Consultancy Services), one underlying architectural pattern: operations engineers required immediate, exact technical answers from thousands of scattered equipment manuals and CAD/CAM specs, while new associates needed reliable, cited guidance on complex organizational policies and security protocols.

Ingestion & Advanced Chunking Harness

Naive fixed-character text splitting breaks tabular specs and truncates machine repair steps mid-sentence. I designed a structure-aware ingestion pipeline to preserve technical layout integrity:

  • Structure-Aware Document Parsing: Used layout-aware PDF parsers to extract schematics, tables, and nested bullet structures from complex vendor manuals without losing tabular alignment.
  • Recursive Header-Based Splitting: Chunked documents at logical H1/H2 section boundaries with a target size of 512 tokens and a 64-token sliding overlap to maintain context continuity across technical procedures.
  • Rich Metadata Injection: Every chunk was enriched with a structured JSON payload containing document metadata: {doc_id, section_title, machine_model, revision_date, security_level, page_number}.
  • Embedding Pipeline: Generated dense vector embeddings using Azure OpenAI text-embedding-3-large (1,536 dimensions) and indexed vectors into ChromaDB collections with HNSW index configuration for sub-10ms retrieval.

Multi-Stage Hybrid Retrieval & Reranking Harness

Finding exact component serial numbers (e.g. PLC-FX3U-64MT) fails with pure vector similarity. The retrieval engine combines dense semantic search with sparse keyword matching:

  • Hybrid Search (Dense + BM25 Sparse): Queries simultaneously execute dense vector cosine search in ChromaDB and BM25 sparse keyword matching over document chunks, merged via Reciprocal Rank Fusion (RRF).
  • Cross-Encoder Reranking: Initial retrieval fetches top-30 candidate chunks. A Cross-Encoder reranker scores each candidate chunk against the exact query intent, selecting the top-5 highest-relevance context blocks to pass to the LLM context window.
  • Role-Based Access Control (RBAC) Filtering: For the onboarding agent, queries dynamically apply metadata filters (user_role == 'engineer' AND clearance_level >= 2) to strictly prevent unauthorized document exposure across departments.

Grounding Guardrails & Evaluation Harness

In manufacturing support, a hallucinated repair step can cause physical equipment damage or line downtime. I implemented strict guardrails and continuous evaluation metrics:

  • Strict Grounding System Prompts: Prompt constraints enforce that answers must be derived strictly from retrieved context. If relevance score is below 0.70, the agent explicitly states "Information not found in technical manuals" and routes to an on-duty engineering manager.
  • Citation Engine: Automatically appends verifiable footnotes to every response, linking directly to [Doc: SMT_Line3_Manual.pdf, Page 142, Section 4.2] so technicians can cross-reference physical documentation.
  • Ragas Evaluation Pipeline: Automated test harness powered by Ragas evaluating test query sets across three core metrics:
    • Faithfulness Score (> 0.94): Verifying zero factual contradiction or hallucination against source manuals.
    • Answer Relevance (> 0.92): Ensuring direct, actionable repair steps for technicians.
    • Context Precision (> 0.90): Verifying minimal retrieval noise in context windows.

Operational Outcome & Impact

  • Faster Maintenance Triage: Reduced average manual lookup time for line technicians from 35 minutes to under 2 minutes per incident.
  • Accelerated Onboarding: Onboarding assistant provided 100% cited answers for new hires on policy, security, and manager routing, cutting onboarding support overhead by 40%.
  • Zero High-Severity Hallucinations: Guardrails prevented incorrect machinery instruction dispatches across 12+ months of production usage.
